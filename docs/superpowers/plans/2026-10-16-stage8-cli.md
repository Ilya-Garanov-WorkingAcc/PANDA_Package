# Стадия 8 — командная строка (фаза 7) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** команда `panda` (shapes, profile, fit, run) — тонкая обёртка над Python API с кодами возврата 0 / 1 / 2.

**Architecture:** пакет `panda_md.cli` на typer: `options.py` — разбор значений опций и поры, `pipeline.py` — этапы
конвейера (профиль, фит, вывод) теми же вызовами, что в API, `config.py` — файл настроек `panda run` (pydantic, TOML),
`app.py` — команды и `main()` с переводом исключений в коды возврата. Типы пор по имени — `panda_md.pores.registry`.

**Tech Stack:** typer ≥ 0.26 (click встроен), tomllib / tomli (Python 3.10), pydantic v2.

**Spec:** `docs/superpowers/specs/2026-10-01-panda-architecture-design.md` §8, §10; решение D28.

## Global Constraints

- Зависимости: `numpy`, `scipy`, `pydantic` (v2), `typer` (§10); MDAnalysis — только в `trajectory/reader.py`
  (лениво), matplotlib — только в `panda_md.plotting`.
- Код возврата: 0 — успех, 1 — ошибка входа, 2 — фит завершён с флагами проблем (§8).
- pydantic вместо датаклассов, `class X(str, Enum)`, типы у всех полей, black 120, ruff, mypy strict.
- Сообщения пользователю — по-русски, без traceback для ошибок входа.

## Review Focus

1. Ошибки разбора команды typer/click (нет аргумента, неверное значение перечисления) — у click код 2, а 2 у нас —
   флаги фита: должен быть код 1.
2. Профиль без метаданных (.csv из чужой программы) и набор профилей по блокам (.npz от `panda profile`) — `panda fit`
   различает их и фитирует среднее по блокам.
3. Размеры поры не заданы: щель по атомам стенок; частично заданные размеры — ошибка, а не тихая подмена.
4. Пути в `panda.toml` относительные — от каталога файла, а не от текущего каталога.
5. `--plot` без matplotlib — понятная ошибка до долгого фита.
