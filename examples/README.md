# Examples

| Script | What it shows | Needs |
|--------|---------------|-------|
| `01_synthetic_fit.py` | model → synthetic profile → fit; comparison of all shapes | `panda-md` |
| `02_md_pipeline.py` | full pipeline on your MD trajectory: pore from the walls, profiles by blocks, shape comparison, fit per block, 2D map, figures | `panda-md[md,plot]`, a trajectory |
| `03_saved_profiles.py` | analysis of saved profiles: water in a graphite slit pore (θ ≈ 171°) | `panda-md` (`[plot]` for `--output`), the repository checkout |
| `04_stability_diagram.py` | which shape has the lowest capillary energy over (L/H, φ) | `panda-md` (`[plot]` for `--output`) |
| `05_custom_shape.py` | a new interface shape declared in a user script and registered with the slit pore | `panda-md` |
| `test_panda.ipynb` | full check of the library on synthetic data and on real trajectories (graphite slit with water and decane, benzene on SOLD, calcite): every step is a PASS / FAIL / SKIP check, the summary goes to `panda_test_results/report.json`; generated by `build_test_notebook.py` | `panda-md[md,plot]`, Jupyter, the trajectories (paths in the first cell) |
| `panda.toml` | settings file for `panda run`: profile from a trajectory + fit | `panda-md[md]` |

Run from the repository root, e.g. `python examples/01_synthetic_fit.py`. The notebook runs on the kernel of the
project environment: `uv sync --all-extras`, then in VS Code connected to WSL (or Linux) choose the kernel
`.venv/bin/python`; a Windows kernel opened over `\\wsl.localhost\...` has neither `panda_md` nor the `/mnt/c/...`
paths. Without VS Code: `uv run --with jupyter jupyter lab examples/test_panda.ipynb`. Examples 01, 03, 04 and 05 are run by
the test suite (`tests/test_examples.py`).
